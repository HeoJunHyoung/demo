# Demo Project: 백엔드 핵심 개념 실전 구현

본 프로젝트는 그동안 학습하고 경험한 Spring Boot 백엔드 핵심 지식들을 실제 동작하는 코드로 구현하고 점검하기 위한 데모 프로젝트입니다.

---

## 🎯 프로젝트 목적

* **실전 코드 구현**: 이론으로 알고 있는 개념들을 실제 코드로 직접 구현하여 동작 검증
* **전체 흐름 연결**: Web, Security, Data, Cache, Test까지 백엔드 모듈 전반의 유기적 연결성 확인
* **트러블슈팅 & 디버깅**: 개발 과정에서 발생하는 문제 추적 및 테스트 작성 연습

---

## 🛠 주요 구현 예정 항목

* **REST API & Validation**: 컨트롤러 설계, 요청 검증, 공통 예외 처리
* **Spring Security & JWT**: 인증/인가 필터 체인 및 토큰 기반 인증
* **JPA & QueryDSL**: 엔티티 연관관계 매핑, N+1 방지, 동적 쿼리 작성
* **Redis**: 데이터 캐싱 및 인메모리 데이터 활용
* **테스트 & 디버깅**: JUnit5/Mockito 단위·통합 테스트 및 디버깅 기법 적용

---

## 🚀 Tech Stack

* **Language**: Java / Kotlin
* **Framework**: Spring Boot 3.x
* **Security**: Spring Security, JWT
* **Database**: MySQL, Redis
* **ORM / Query**: Spring Data JPA, QueryDSL
* **Build Tool**: Gradle
* **Testing**: JUnit 5, Mockito
